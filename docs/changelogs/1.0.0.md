# BLU Forever 1.0.0

Released 2026-09-20.

Initial WoW Forever (Classic beta, Interface `16001`) build, forked from
Retail BLU v8.0.8.

- Retained features: Level-Up, Quest, Reputation, Honor rank, Combat
  triggers, Loot (placeholder tab), the minimap button, custom sounds, and
  the profile system with `BLUForeverDB`.
- Removed every retail-only system that cannot exist on the Forever client:
  Achievements, Battle Pets, Collectibles, Delves, Housing, Prey, Renown, and
  the Trading Post — modules, options tabs, sound categories, registry
  entries, config defaults, and default WoW sound muter IDs.
- Slash commands moved to the `/bluf` group with `/blu` retained
  (`/bluesound` was dropped).

Requires RGX-Framework v2.7.5 or later.

# v1.1.5-beta.2 - 2026-11-05

- New Loot tab: pick an Item Looted sound and an Appearance Collected sound. Both start as None.
- Honor tab: added Honor Gained and PvP Victory sounds next to the rank-up sound. Both start as None.
- Item Looted plays when a new item reaches your bags (drops, vendors, mail and crafting all count).
- Requires RGX-Framework 2.14.0, which provides the new loot and honor events.

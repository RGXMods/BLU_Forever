# BLU Forever 1.1.0

Released 2026-09-20.

- New flavor capability system (`core/systems/flavors.lua`): feature tabs are
  declared with the client flavor they require across the four supported
  versions (Retail, Mists Classic, Classic Era, WoW Forever), and tabs the
  current client cannot fire render greyed-out with a pointer to the build
  that supports them instead of being hidden or deleted.
- The full BLU feature grid is back: Achievement, Battle Pets, Delve,
  Housing, Prey, Renown, and Trading Post return as greyed-out tabs on
  WoW Forever, preserving the Retail/Classic layout while showing what
  exists in the other builds.
- New Death tracker for hardcore and self-found play: lifetime death count,
  last death time, hardcore status display, counter reset, and a configurable
  death sound trigger (PLAYER_DEAD).
